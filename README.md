# 🤖 AI Churn Assistant

An AI-powered customer churn prediction dashboard built with **Python, Streamlit, Scikit-learn and Plotly**.

## 📌 Project Overview

AI Churn Assistant is an interactive dashboard that predicts customer churn using a Machine Learning model. It enables CRM teams to identify high-risk customers, analyze customer behavior and take proactive retention actions.

---

## 🚀 Features

- 🔍 Individual customer churn prediction
- 📂 Batch customer analysis via Excel upload
- 🤖 AI-powered risk scoring
- 📊 Interactive dashboards and charts
- 💡 AI-based customer retention recommendations
- 📥 Export analysis results to Excel
- 📈 KPI dashboard for business insights

---

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/elifnraydinoglu/AI-Churn-Assistant.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
